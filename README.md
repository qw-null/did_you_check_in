# 打卡了吗

原生微信小程序 + JavaScript + 微信云开发。AppID：`wxb7e6889ef5fe7e88`。

当前为 **0.5.0「我的打卡」核心功能**：在已由账号持有人验证的 0.4.0 活动目录与运营工作台上，新增加入/移除/重新加入清单、今日/全部视图、每日与一次性手动完成、今日进度及完成历史。日期和状态由服务端决定，完成不能撤销或补卡。升级需按[云端部署指引](docs/身份服务部署指引.md)补齐索引、重新部署 `catalog` 并编译前端；0.5.0 尚需真实云端和真机验收。投稿与反馈处理仍属后续阶段。

## 在微信开发者工具打开

1. 使用有开发权限的微信账号登录微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录，即包含 `project.config.json` 的文件夹。工具会从 `miniprogram/` 读取小程序代码。
3. 确认 AppID 为 `wxb7e6889ef5fe7e88`，后端服务选择微信云开发（如果导入界面有该选项）。
4. 编译项目，检查“活动广场 / 我的打卡 / 我的”切换，并从“我的”进入关于页。

管理分包使用 Vant Weapp 1.11.7 的 Uploader，所需官方组件文件已生成在 `miniprogram/admin/vendor/vant/`，直接导入即可编译，无需执行开发者工具“构建 npm”。依赖锁定在根目录；维护时运行 `npm ci` 和 `npm run build:vendor` 可从官方包重新生成所需文件。微信开发者工具负责 WXML/WXSS 与运行时处理。

## 云环境配置

已将你提供的环境 ID 写入项目配置：

```js
// miniprogram/config/cloud.js
module.exports = {
  envId: 'cloud1-d0gyv1btk3ea9e858',
};
```

在微信开发者工具中重新编译后会调用原生 `wx.cloud.init`；“初始化”仅指客户端 SDK 初始化，不表示环境归属、数据库、登录和云函数已经部署或联调。需要在工具中确认当前 AppID 可选择该环境。

已按用户说明采用**文档型云数据库**路线，实际环境模式仍需在控制台确认。按[云端部署指引](docs/身份服务部署指引.md)创建/补齐 `users`、`admin_bindings`、`user_activities`、`activity_views`、`checkins`、`platforms`、`activities`、`catalog_images`、`catalog_snapshots`、`catalog_requests`、`audit_logs` 集合并关闭客户端读写，然后部署 `identity` 与 `catalog` 云函数。0.4.0 写入要求目标 CloudBase 环境真实支持事务；部署前先按指引验证事务和组合索引。

活动采集已精简为基本信息、参与方式和期限三组：活动信息合并奖励与门槛，参与步骤支持逐条文字及图片。目标小程序可填写 `#小程序://…` 分享地址；管理员登记真机跳转核验后，详情提供直接打开及复制回退。此次更新需补建 `catalog_images`、重新部署 `catalog` 并编译前端；图片上传与跳转仍需真实云端及真机验收。

步骤图片使用 Vant Uploader 选择压缩图，不限制原图业务体积。优先采用微信原生压缩，仍是 HEIC 或体积过大时回退 Canvas JPEG，内部目标 900KB。压缩后的文件通过 `wx.cloud.uploadFile` 原生上传云存储，再由 catalog 校验和登记；图片不再作为 Base64 放入云函数请求。**无需自有服务器、域名或 uploadFile 合法域名配置；本次需重新部署 catalog，并按部署指引设置云存储暂存区安全规则**。数据库仍禁止客户端读写；云存储仅允许写入本人创建的暂存图片，正式图片仍由云函数写入。开发者工具的 HEIC 选择/解码能力不能由 UI 组件补齐，须在 iPhone 微信相册测试。

微信登录识别账号与读取头像昵称是两种能力。不会静默抓取真实微信头像昵称；新用户先显示默认头像与“微信用户”，主动使用“编辑资料”中的头像选择和昵称填写后保存。头像通过云函数上传到当前环境的 `user-avatars/`，客户端不需云存储直接写权限，展示使用服务端生成的临时链接。

三项统计来自云端：打卡活动为当前 active 清单数；浏览活动、完成活动分别按对应记录的 `activity_id` 去重。0.5.0 加入与完成直接写入这些统计的事实记录，返回“我的”时重新读取；同一活动跨日完成不重复增加“完成活动数”。未部署、缺少集合或读取失败显示“—”和重试。

“我的打卡”提供今日待完成/已完成及全部清单五类筛选。已完成活动随后被暂停、结束或移除，仍计入当天完成数；移除只停止后续待办。一次性活动完成后跨日及重加均不会重置。完成确认明确显示北京时间日期，跨日新请求须刷新后再次确认；响应丢失时保留原请求 ID 与日期，跨日重试不会静默创建新一天的记录。“我的 → 打卡记录”按服务端完成时间倒序、每页 20 条，保留完成时标题/平台快照，受限内容仍屏蔽。

详细开通步骤见 [微信云开发开通指引](docs/微信云开发开通指引.md)。AppID 与 EnvID 是公开配置标识，不在客户端放 AppSecret、腾讯云密钥或管理员凭证。

## 本地检查

安装 Node.js 18 或更高版本后，在仓库根目录运行：

```sh
npm run check
npm test
```

静态检查覆盖 JSON、JS 语法、主包/分包与组件注册、事件方法、底部导航和图片文件。测试采用本地替身验证身份、权限及页面异步状态，不替代云端 SDK、微信开发者工具和真机检查。
