# 打卡了吗

原生微信小程序 + JavaScript + 微信云开发。AppID：`wxb7e6889ef5fe7e88`。

当前为 **0.2.0 身份与管理员核验代码**：保留原生三个底部页面与关于页，新增身份云函数、个人身份入口和独立管理分包。真实身份与权限需完成下方部署后才能使用；活动和打卡仍在开发中，不使用模拟账号、活动、记录或管理员权限。

## 在微信开发者工具打开

1. 使用有开发权限的微信账号登录微信开发者工具。
2. 选择“导入项目”，目录选择本仓库根目录，即包含 `project.config.json` 的文件夹。工具会从 `miniprogram/` 读取小程序代码。
3. 确认 AppID 为 `wxb7e6889ef5fe7e88`，后端服务选择微信云开发（如果导入界面有该选项）。
4. 编译项目，检查“活动广场 / 我的打卡 / 我的”切换，并从“我的”进入关于页。

当前前端没有 npm 依赖，不需要安装依赖、执行“构建 npm”或编译 TypeScript。微信开发者工具负责 WXML/WXSS 与运行时处理。

## 云环境配置

已将你提供的环境 ID 写入项目配置：

```js
// miniprogram/config/cloud.js
module.exports = {
  envId: 'cloud1-d0gyv1btk3ea9e858',
};
```

在微信开发者工具中重新编译后会调用原生 `wx.cloud.init`；“初始化”仅指客户端 SDK 初始化，不表示环境归属、数据库、登录和云函数已经部署或联调。需要在工具中确认当前 AppID 可选择该环境。

已按用户说明采用**文档型云数据库**路线，实际环境模式仍需在控制台确认。下一步按[身份服务部署指引](docs/身份服务部署指引.md)创建 `users`、`admin_bindings` 集合并关闭客户端读写，然后部署 `identity` 云函数，再进行微信端真实调用。

详细开通步骤见 [微信云开发开通指引](docs/微信云开发开通指引.md)。AppID 与 EnvID 是公开配置标识，不在客户端放 AppSecret、腾讯云密钥或管理员凭证。

## 本地检查

安装 Node.js 18 或更高版本后，在仓库根目录运行：

```sh
npm run check
npm test
```

静态检查覆盖 JSON、JS 语法、主包/分包与组件注册、事件方法、底部导航和图片文件。测试采用本地替身验证身份、权限及页面异步状态，不替代云端 SDK、微信开发者工具和真机检查。
