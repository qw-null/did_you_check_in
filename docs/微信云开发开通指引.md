## 推荐方案

使用微信云开发（腾讯云 CloudBase）承接云函数、数据库与文件存储，前端使用微信原生小程序能力。云开发是托管后端服务，仍需为小程序创建和开通具体环境，不等于账号自动拥有永久免费的后端。

首版采用文档型云数据库与原生 `wx.cloud` 接入；前端没有额外 npm 依赖，云函数通过 `wx-server-sdk` 访问数据。个人数据、管理员权限与关键写入通过受控服务端接口处理。唯一索引、事务及请求幂等仍需在实现阶段验证，不能只依赖客户端按钮状态。

## 开通步骤

1. 使用小程序管理员或有相应权限的开发者微信登录微信开发者工具。
2. 在微信开发者工具导入本仓库根目录，工具通过 `project.config.json` 加载 `miniprogram/`。确认 AppID 后编译，再点击工具中的“云开发”。前端当前没有 npm 依赖，不需要构建 npm 或编译 TypeScript。
3. 首次开通时按页面完成服务条款与服务角色授权，然后创建环境。环境名称可用 `daka-dev`，实际 EnvID 由平台生成，两者不是同一项。
4. 查看账号当前提供的开发期资格、套餐、额度和到期规则，再确认开通。若页面要求选择数据库类型，首版优先使用文档型；不要在未经评估时切换到 PostgreSQL 模式。
5. 等待初始化完成，在环境信息或设置中复制完整的环境 ID（EnvID）。

通过微信开发者工具创建时，环境会自动关联当前小程序。如改用网页版控制台，优先选择“使用微信公众平台账号登录”；已有独立腾讯云账号的环境则需按官方流程关联，不假定环境天然属于该小程序。
