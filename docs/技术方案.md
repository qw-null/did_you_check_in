# 首版技术方案

更新日期：2026-10-29。当前实现版本：0.5.0。

## 已确定

- **前端：** 微信原生小程序，JavaScript、WXML、WXSS、JSON。
- **原因：** 当前 MVP 以原生页面与云接口为主，采用 JS 减少类型声明和编译配置，前后端可以共用同一语言。复杂字段和状态在实现时配合必要的 JSDoc 与服务端校验维护。
- **后端：** 微信云开发文档型云数据库与 JavaScript 云函数，不直连 MongoDB。EnvID `cloud1-d0gyv1btk3ea9e858` 已配置；账号持有人确认 0.4.0 已完成验证，0.5.0 仍需更新云函数并验收新增接口。
- **管理界面：** 同一小程序的独立管理分包，页面与 `catalog` 云函数各自校验 `admin_bindings`；写操作要求数据库事务。
- **外部依赖：** 管理分包接入 Vant Weapp 1.11.7 Uploader，官方编译产物及其依赖按需生成到 `admin/vendor/vant/`；主包不注册、不引入该组件。根目录锁定 npm 版本，`npm run build:vendor` 可重建，无需 TypeScript 或开发者工具 npm 构建。
- **资源：** 使用已确认的 V3 双羊头像；底部导航采用原生 tabBar 与自有 SVG 导出的 PNG。

## 本阶段范围

0.4.0 活动目录与运营工作台已由账号持有人确认验证通过。0.5.0 实现广场/详情加入、今日/全部清单、每日/一次性手动完成、移除重加、今日进度与本人历史记录。投稿和反馈处理尚未实现。

个人写接口复用 `catalog`，身份只来自微信云调用上下文。关系 ID 按用户和活动确定，完成 ID 按用户、活动和周期确定，并以数据库唯一索引兜底；`catalog_requests` 用 `ur_` 独立前缀记录用户请求结果。事务先检查用户、既有请求和周期完成，再校验日期/关系/执行条件并原子提交；不接受客户端指定用户或历史完成时间。

全部业务日期采用服务端北京时间，`completed_at` 保存服务端 Date，客户端转换为北京时间展示。`expectedDate` 与当前日期不一致时刷新后让用户重新确认；客户端在发送写操作前持久化请求 ID 和原日期，网络失败/响应异常不更换标识，即使重启或跨日也只能恢复原请求。未知结果明确提示“提交结果待确认”。服务端完成不依赖外部跳转或奖励结果。

快照读取不能单独当作执行依赖的并发锁。新个人写事务增加用户内部 `_checkin_guard`；首次完成还写入关系、活动和平台的同步字段，加入写入活动和平台。与账号停用、移除、暂停或平台停用竞争时，通过写冲突重新核验；内部字段不递增运营内容 `revision`，不改变运营 `updated_at`。这是防止写偏斜的同步元数据，不对客户端开放。目标环境须验证 SDK 的写冲突重试行为，失败即中止，不能降级为独立写。平台同步字段会增加同平台并发写争用，公开放量前需做真实并发和延迟验收。

今日进度为当前待办与当天完成事实的并集，不把已移除/已暂停的当天记录丢弃。一次性完成保留固定 `once` 周期，重加不能重置。清单按活动 ID 稳定分页；统计扫描同用户关系/当日/一次性记录，各最多 5000 条，超出返回明确错误而非静默截断。历史按 `completed_at desc + _id desc` 每页 20 条，使用完成时标题和平台快照，当前内容受限时再次脱敏。页面显示/从外部小程序返回和下拉刷新会重新读取；持续前台停留跨日时，下次写操作仍由服务端拒绝旧日期并引导重确认。

个人资料保存仅接受昵称和用户主动选择的图片，头像由 identity 云函数上传并生成临时访问链接，不给客户端开放 users 表或头像目录的直接写权限。新用户在未填写资料时显示默认头像与“微信用户”，不调用旧式接口声称已自动取得真实微信头像昵称。

活动采集使用 `activity_info` 合并奖励、资格和注意事项；旧字段兼容读取，列表摘要由信息第一行生成。参与步骤保存为 `{text, images: [fileID]}` 数组，兼容旧字符串列表。Vant Uploader 提供选择、缩略图、进度、失败重试与删除，失败项须重试或移除后才能保存。catalog 核验管理员并分配随机暂存路径，客户端通过 `wx.cloud.uploadFile` 原生上传，无需业务域名白名单或预签名接口；服务端校验返回的云文件 ID 属于当前环境及分配路径后绑定。完成后服务端下载并校验真实格式与成品大小，另存正式路径并在事务中复核管理员、登记文件和完成凭证。存储规则仅允许客户端写入 `activity-step-staging/` 下本人创建的文件，普通账号即使上传暂存文件也不能登记为正式图片；数据库和正式图片仍禁止客户端直接写入。移除引用后不立即删除可能被其他活动引用的文件。

步骤图片原图不设业务大小上限；Vant 选择时请求压缩，原生压缩结果符合真实 JPG/PNG/WebP 文件头及 900KB 目标时直接使用，否则通过 Canvas JPEG 导出，最长边从 2560 像素起先降质量再降尺寸。客户端只读成品前 12 字节，不读取整图 Base64；上传完成或失败后清理成品和中间文件。云函数的 1MB 校验针对压缩后的成品，微信或设备无法解码时明确失败。凭证和临时文件信息复用 `catalog_images`，凭证业务有效期 10 分钟；完成/取消尽力删除暂存文件，网络中断或客户端再次写入可能留下孤立暂存文件，需维护时按暂存目录配置生命周期清理。旧 Base64 上传接口仅保留兼容。

小程序目标地址保存完整 `#小程序://…` 到 `target_address`，由用户点击后使用 `wx.navigateToMiniProgram({shortLink})`；旧 AppID/路径兼容读取。管理员核验时显式确认真机验证后才开启直达并记录依据，编辑后关闭。打开前服务端重新核验执行状态，失败或版本不支持时提供复制和图文步骤；网页暂保持复制。开始/结束日期按北京时间展示，非固定期限清空结束日期。

统计读取 user_activities 中 active 关系数量，并用文档数据库聚合按 activity_id 去重统计 activity_views 与 checkins。0.5.0 真实写入关系和完成记录，沿用 identity.summary，无需修改统计接口；返回“我的”重新读取。集合与索引见部署指引；失败显示不可用，不能默认当成 0。
